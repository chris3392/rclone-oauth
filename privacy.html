Privacy Policy

This application is used for personal access to Google Drive from Ubuntu using rclone.

Google Drive data is accessed only at the user's request for file synchronization, file copying, and automated file processing.

Google user data is not sold, shared with third parties, or used for advertising purposes.

The application does not operate a separate server that stores Google user data. Files are transferred directly between Google Drive and the user's own computer using rclone.
